# Fill Color - Kid's Coloring App 🎨

A fun, interactive Android application built for kids using **Jetpack Compose**. Kids can choose a picture template, color it using tap-to-fill or freehand brush tools, compare their artwork against a sample reference image, and receive an accuracy percentage score with stars!

---

## 🌟 Features

- 🖼️ **Multiple Coloring Templates**: Fruits (Apple), Shapes (Happy Star), Nature (Sun & Cloud, Flower), Buildings (Cozy House).
- 🪣 **Tap-to-Fill (Flood Fill)**: Tap any enclosed region to fill it instantly with color.
- 🖌️ **Freehand Brush & Eraser**: Draw or erase freely with adjustable brush sizes.
- 🎨 **Kid Palette**: Bright, cheerful primary & secondary colors.
- ↩️ **Undo & Clear Canvas**: Allows kids to correct mistakes easily.
- 🔍 **Target Reference View**: Floating sample card so kids can refer to the target color scheme.
- 🏆 **Color Comparison & Score**: Pixel-matching algorithm calculates accuracy percentage score and rewards stars (⭐⭐⭐) with encouraging feedback.

---

## 🛠️ Built With

- **Kotlin**
- **Jetpack Compose (Material 3)**
- **Android Graphics Canvas & Bitmaps**
- **Queue-based BFS Flood Fill Algorithm**

## 🚀 How to Build & Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/FillColor.git
   ```
2. Open the project in **Android Studio**.
3. Build and run on an Android device or emulator running **Android 7.0 (API 24)** or higher.
